## 이 과목이 가르치는 것

- 코드의 *양*이 아니라 **판단의 질**
- 5대 역량: **A** 슬라이스 · **B** 검증 · **C** 근거 · **D** 프라이버시 · **E** 실패 처리

- `Embedding`·`ThemeAssigning(SameTopic)`·`Consolidation`·`Curation`
- 스파이크 `binary_spike`/`embed_spike3` 재현
- 커밋 `e66c50f`·`0baf42d`·`24194a3`

---

## 왜 임베딩을 못 믿나 (3주 — 핵심 슬라이드)
- 합쳐야 할 쌍 **0.209** < 합치면 안 될 쌍 **0.353**
- → *유사도 순위가 어긋남* → 단일 임계값 불가
- ∴ 임베딩 군집화 폐기 → FM 배정 → 그래도 기기서 불안정
- **결론: best-effort + 큐레이션**
