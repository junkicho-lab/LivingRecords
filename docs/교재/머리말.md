# 머리말

이 책은 한 iOS 앱 **"생동하는 기록(Living Record)"** 이 *구상 → 검증 → 67개 커밋*을 거쳐 완성되는 전 과정을, **하나씩 다시 공부할 수 있게** 묶은 통합 교재다.

겉보기엔 음성 메모 앱이지만, 이 책이 가르치는 것은 코드가 아니라 **판단의 흐름**이다 — 무엇을 자동화하고 무엇을 사람에게 남길지, 무엇을 믿고 무엇을 검증할지, 언제 밀고 언제 되돌릴지.

## 누구를 위한 책인가
- **학생** — SwiftUI/SwiftData를 배우며 *설계 사고*를 익히려는 사람.
- **강사** — 프로젝트 기반(PBL) 강의를 운영하려는 사람(8주 계획·루브릭·문제은행 포함).
- **독학자** — 실제 앱의 결정과 실패를 따라가며 혼자 공부하려는 사람.

> 선수지식: Swift 기본 문법(변수·함수·옵셔널·클로저). SwiftUI/SwiftData는 본문에서 다룬다.

## 이 책의 구성 (4부)

- **제1부 · 본문(학습 보고서)** — 9페이즈·25개 학습 단위로 전 과정을 해설. *이 책의 척추.*
- **제2부 · 설계 원자료** — 구상(결정 토론)·기술 검증(스파이크)·단계별 계획·완성본 사용법. *왜 그렇게 정했는지의 1차 사료.*
- **제3부 · 강의 운영(강사용)** — 8주 강의계획서·채점 루브릭·모범답안집.
- **제4부 · 학생 자료** — 워크북·문제은행·포트폴리오 템플릿.

> 발표용 **슬라이드(Marp)** 는 선형 책에 맞지 않아 별도 파일로 둔다: `주차별-슬라이드개요.md`(영문 `en/slides.md`). `marp` 또는 VS Code Marp 확장으로 PDF/PPT 변환.

## 읽는 길

| 목적 | 추천 경로 |
|---|---|
| **자습** | 1부(보고서)를 페이즈 0→8 순서로 + 각 단위의 원자료(2부) 교차 읽기 |
| **8주 강의(학생)** | 4부 워크북을 매주 채우며 1부를 참고 |
| **8주 강의(강사)** | 3부 강의계획서 → 매주 1부 단위 + 슬라이드, 평가는 루브릭·문제은행 |
| **앱 사용법만** | 2부의 *사용설명서* |

**공부법(핵심):** 각 단위에서 ① *왜*(결정)를 먼저 읽고 → ② 관련 코드 파일을 한 줄씩 → ③ 커밋 diff로 *무엇이 추가됐나* 확인 → ④ 복습 질문에 스스로 답.

## 학생판 만들기 (강사)
이 통합본(마스터판)에는 **정답·모범답안·루브릭**이 포함된다. 학생 배부용은 빌드 스크립트의 학생 모드로 만든다:

```bash
docs/교재/build.sh ko --student     # 강사용 자료 제외 + 문제은행 정답 절 제거
```

## 함께 보는 것
- **소스 코드** — 저장소 `LivingRecord/`(42개 Swift + 위젯), `spike/`(24개 검증 스크립트).
- **커밋 이력** — `git log --reverse --oneline` (S0 스캐폴딩 → 전체 점검).
- **영문판** — `docs/en/`(전 문서 영역).

## 표기
- 코드 식별자·파일명·커밋 해시는 원문 그대로(저장소와 일치).
- 한국어 어미(겠/해야/하자 등)가 *교훈 자체*인 곳은 한국어를 살린다("결정적 규칙이 온디바이스 LLM을 이겼다").
