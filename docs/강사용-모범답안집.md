# 1주차 · 방법론과 구상·검증

### 빈칸 정답
1. **지속** · 2. **수직 슬라이스** · 3. **스파이크** · 4. **(실행)검증 → 커밋** · 5. **사용자(사람)**
💡 *왜:* "지속"은 이 앱의 차별점. 흔한 음성메모와 가르는 단 한 단어. 4번은 "빌드 성공 ≠ 동작"을 각인.

### 코드 탐험 모범답안
- 결정 예: 프라이버시 하이브리드 / 2단계 증류 / 분류=주제(emergent+통합) / 봉인=트리거 흡수 — 중 2개.
- 미결 예(concept §5): 템플릿 선택 UX / 실음성 WER / 앱 이름(당시) / Obsidian 양방향 — 중 2개.

### 스파이크 모범 해석
- `intention_spike2`: "FM은 실행마다 1~6/10으로 출렁, 어미 게이트는 10/10" → *결정적 규칙이 환경에 안 흔들린다*가 핵심 메시지.

### 복습 모범답안
1. **차별점:** "앞으로 무엇을 *지속*할 것인가를 돕는다 — 증거를 모아 사람이 결정하도록." (요약·검색이 목적이 아님)
2. **봉인:** "가장 사적인 생각을 *기기 밖으로 안 나가게* 한다 — 클라우드 종합·갤러리 제외, 별도 폴더." 프라이버시를 *포착 순간의 한 동작*으로 해결.

### 토론 진행 노트
- 발문: "여러분의 메모 앱과 이 앱의 차이를 한 단어로?" → '지속'을 끌어내기.
- 흔한 오해: "스파이크 = 프로토타입". 차이 강조 — *버리는* 실험, 빠르게, 사실만 얻으면 폐기.

# 3주차 · v1 데이터 (Obsidian 미러 · 분류·통합) ⭐

### 빈칸 정답
목표줄: **사용자** · 1. **security-scoped** · 2. **중심화** · 3. **유사도** · 4. **구조화(Bool 판단)** · 5. **best-effort**
💡 *왜:* 이 주의 핵심 = *완벽한 자동분류는 불가능*하다는 걸 받아들이는 것. "자동은 출발점, 정리는 사람이."

### 코드 탐험 모범답안
- frontmatter 키(`ObsidianMirroring.swift:markdown`): `id, type, created, source`(+ 조건부 `energy`, `theme`). 본문 뒤 `주제: [[...]]` 링크.
- `ThemeAssigning.swift`: `@Generable struct SameTopic { let same: Bool }` — *번호(index) 대신 주제별 "같은 분야?" Bool*. (index는 기기 FM이 0으로 쏠림)

### 스파이크 리포트 — 만점 기준
- 표(입력/기대/실제/일치) + **인과 해석**: "합쳐야 할 쌍(수업1·2=0.209) < 합치면 안 될 쌍(등산·음식=0.353) → 유사도 순위가 어긋나 *어떤 단일 임계값으로도* 둘 다 만족 불가 ∴ 임베딩 군집화 폐기 → FM 의미 배정. 단 기기선 불안정 → best-effort+큐레이션."
- 채점: 인과(∴)가 있으면 C 탁월. 결과 재진술만이면 보통.

### 복습 모범답안
- **과분할이 과병합보다 안전한 이유:** "잘게 갈라진 건 *합치기* 큐레이션으로 쉽게 되돌리지만, 잘못 합쳐진 건 다시 *나누기*가 어렵고 반복 카운트(신호)를 오염시킨다. 그래서 자동은 보수적으로 갈라두는 쪽."

### 토론 진행 노트
- 발문: "임베딩이 비슷한 걸 잘 찾는다는데, 왜 못 믿지?" → *순위가 어긋난다*(절대 거리 X)를 스파이크 숫자로 보여주기.
- 오개념: "FM이 macOS에서 5/6이면 기기서도 되겠지" → 스파이크 ⑥-b: *기기 동작이 다르다*. "환경 차"를 각인.

### 복습 모범답안

### 토론 진행 노트

### 코드 탐험 모범답안
- 의미 검색(`Search.swift:SemanticSearch.similar`): 임계값 **0.30**, 상위 **6**.

### 복습 모범답안
- **HKDF로 유도하는 이유:** "암호구절은 *약하고 길이가 제멋대로*다. HKDF로 고정 길이의 강한 키를 유도하고, 랜덤 salt로 같은 암호라도 매번 다른 키 → 사전공격·재사용 방어."
- (의미 검색이 리턴에서만) "매 타자마다 임베딩하면 낭비·느림. 전문 검색은 라이브, 의미는 *검색 실행* 시에만."

### 직접 해보기 — 채점 포인트
- 트리거: 실기기에서 액션버튼/Siri로 *앱이 열리며 녹음 시작*까지. 시뮬레이터 불가 인지.
- 백업: `backup_spike`로 *틀린 암호 → 복호화 실패*를 확인했는가(보안 핵심).

### 토론 진행 노트
