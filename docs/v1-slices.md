# 생동하는 기록 — v1 수직 슬라이스 계획

> 작성: 2026-06-04 · 근거: `concept.md`(결정), `spike-findings.md`(검증)
> 플랫폼: iOS 26+ (Swift/SwiftUI, SwiftData). 스파이크는 macOS CLI로 검증 → 앱 구현체로 포팅.

## 워크플로 (feedback-app과 동일)
- **수직 슬라이스**: 한 흐름을 UI~저장까지 관통. 각 슬라이스 = **구현 → 실제 실행 검증 → 커밋**.
- **앞 슬라이스가 실제로 돌아간 뒤** 다음으로. 막히면 범위를 더 좁힌다.
- 커밋 메시지에 슬라이스 태그: `feat(S1): 포착→저장→목록`.
- 컴포넌트는 **인터페이스로 추상화**(Transcriber/LocalSynthesizer/ProsodyAnalyzer/Embedder/DeepSynthesizer/ObsidianMirror).

## 슬라이스

### S0 · 스캐폴딩
- **목표**: 딛고 설 바닥. Xcode iOS 26+ 프로젝트, SwiftData 모델(Capture/Theme/Digest/Decision), 6개 인터페이스(빈 구현), 앱 셸·탭.
- **검증**: 빌드·실행, 빈 화면 뜸. 모델 마이그레이션 OK.
- **의존**: 없음.

### S1 · 포착 → 저장 → 목록  ⭐핵심(마찰 0)
- **목표**: "말하면 저장되고 목록에 뜬다." 녹음 버튼 → SpeechTranscriber 전사 → Capture(텍스트) SwiftData 저장 → 목록 표시. 텍스트 폴백.
- **포함**: 포착 화면(녹음+텍스트칸, **분류 UI 없음**), 백그라운드 전사(fire-and-forget), 목록.
- **검증**: 한국어 발화 → 텍스트 저장·표시. 앱 죽여도 영속. (실제 사람 음성 WER 첫 측정)
- **의존**: S0. **스파이크 재사용**: `stt_new.swift`(SpeechTranscriber).

### S2 · 에너지 + 봉인
- **목표**: 포착 순간 prosody 에너지 점수(vDSP) 추출 + **오디오 폐기**(절충안 C). 봉인(꾹 누르기) 포착.
- **포함**: ProsodyAnalyzer 구현(음량·피치변동·말속도→각성도), Capture에 에너지·봉인 필드, 목록에 에너지 표시.
- **검증**: 흥분된 발화 vs 덤덤한 발화의 점수 차. 오디오 파일 안 남음. 봉인 표시.
- **의존**: S1.

### S3 · Obsidian 미러
- **목표**: 포착을 옵시디언 볼트에 마크다운으로 **단방향 미러**. frontmatter+본문. **봉인 제외**.
- **포함**: ObsidianMirror 구현, 볼트 폴더 선택(security-scoped bookmark), 파일명·폴더 규칙.
- **검증**: 포착 시 .md 생성, Obsidian에서 열림. 봉인은 미러 안 됨.
- **의존**: S1(+S2 봉인). 

### S4 · 분류·통합 (Theme)
- **목표**: emergent 태깅 + 임베딩 통합으로 Capture를 Theme으로 묶기. 큐레이션(이름변경·합치기·나누기).
- **포함**: LocalSynthesizer(Foundation Models + **MLX 폴백**: 가드레일 차단 시), Embedder(NLContextualEmbedding **+ 중심화**), 유사도 병합·임계값, Theme 화면, Obsidian 주제=`[[위키링크]]`.
- **검증**: 비슷한 포착이 한 Theme로 모임. FM 차단 문장도 폴백으로 태깅됨. 합치기/나누기 동작.
- **의존**: S1. **스파이크 재사용**: `embed_spike3.swift`(중심화), `fm_spike2.swift`+`mlx`(폴백).

### S5 · 일일 정리 (로컬)
- **목표**: 하루 포착을 가벼운 회고로(로컬). 주제별 묶음 + 처음/또 나온 생각 + 에너지 스냅샷 + 내일 질문 1개. Obsidian에도 기록.
- **검증**: 하루치로 일일 Digest 생성·표시·미러.
- **의존**: S4.

### S6 · 주간 정리 + 지속 후보 + 결정  ⭐핵심 가치
- **목표**: 반복(진화/맴돎)+에너지 → "지속 후보" 뷰 + 결정 프롬프트[지속/보류/접기]. 결정 저장·피드백. **클라우드 깊은 종합 옵트인**(2단계 증류→Claude) + 동의 모델(토글+봉인예외+전송로그).
- **검증**: 일주일치로 후보·배지 표시, 결정 저장. 클라우드 토글 시 증류층만 전송·로그 기록. OFF면 로컬만으로도 작동.
- **의존**: S4, S5. **스파이크 재사용**: 증류·통합.

### S7 · 기간 정리 (기본형)
- **목표**: 임의 구간 반복 + 결정 로그. (실행추적·연결·냉각은 post-v1)
- **검증**: 한 달 구간 정리 생성.
- **의존**: S6.

## v1 경계 재확인
- **v1**: 포착·에너지·봉인·Obsidian미러·분류통합·큐레이션·일일·주간(+결정·클라우드옵트인)·기간(기본형).
- **post-v1**: 실행추적·연결·냉각 신호, 양방향 Obsidian, iCloud 동기화, 커스텀 템플릿, 액션버튼/AirPods 트리거, Android.

## 시작점
- **S0(스캐폴딩) → S1(포착 핵심)**부터. S1이 실제 한국어 음성으로 돌면 앱의 심장이 뛰는 것.
