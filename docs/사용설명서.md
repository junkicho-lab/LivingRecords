# 생동하는 기록 (Living Record) — 사용 설명서

> 갱신: 2026-06-05 · 대상: 현재 빌드(v1 보관함 → v2 지속 루프 → v3 포착 도달성 → v4 검색 → 위키·되살아남·백업) · 플랫폼: iOS 26+ (iPhone)
> 근거: 실제 소스(`LivingRecord/`), 설계(`concept.md`), 검증(`spike-findings.md`), 계획(`v1~v4-slices.md`)

## 0. 이 앱은 무엇인가

말이나 글로 **생각을 흘려보내듯 포착**하면, 앱이 그것을 **로컬에 보관**하고 **비슷한 생각끼리 주제로 묶고**, 하루·한 주·한 기간 단위로 **돌아볼 거리(정리)** 를 만들어 준다. 궁극의 목적은 한 가지 질문에 답하는 것:

> **"나는 무엇을 지속할 것인가?"**

채점·평가 앱이 아니다. 판단은 사람이 한다. 앱은 **증거(반복·에너지·흐름)를 모아 보여줄 뿐**이고, 지속/보류/접기는 사용자가 정한다.

### 세 가지 흔들리지 않는 원칙
1. **포착은 마찰 0.** 분류·제목·태그를 묻지 않는다. 말하거나 쓰면 끝.
2. **로컬 우선.** 원문·음성·에너지는 기기를 떠나지 않는다. 클라우드는 *선택*이고, 나갈 때도 원문이 아니라 *요약(증류층)* 만 나간다.
3. **결정은 사람이.** AI는 분류·요약·신호 제시까지. "지속할까/접을까"는 사용자 몫.

## 1. 시작하기

### 1-1. 첫 실행
앱을 열면 바로 **포착 탭**이다. 설정 없이도 말하거나 입력해 바로 기록할 수 있다. 다만 두 가지를 미리 해두면 좋다.

### 1-2. Obsidian 볼트 연결 (선택, 권장)
포착·정리를 마크다운 파일로도 **동시에 남기고 싶다면** 연결한다.
- **포착 탭 우상단 톱니(⚙️) → 설정 → Obsidian 볼트 → "볼트 폴더 선택"**
- 폴더를 고르면 이후 모든 포착이 그 폴더 아래에 `.md`로 미러된다.
  - 일반 포착 → `Captures/`
  - 봉인 포착 → `봉인/`
  - 정리(일일/주간/기간) → `Digests/`
- ⚠️ **주의:** 볼트 폴더가 iCloud/드롭박스로 동기화되면 **봉인 포착도 기기를 떠난다.** 봉인의 의미(기기 밖으로 안 나감)를 지키려면 볼트는 로컬 폴더로 둘 것.

### 1-3. 클라우드 깊은 종합 (선택, 기본 꺼짐)
주간/기간 정리를 Claude로 더 깊게 종합하고 싶을 때만 켠다.
- **설정 → 클라우드 깊은 종합 → 토글 ON + Claude API 키 입력 → "키 저장"**
- 키는 기기 **Keychain**에 저장된다(코드·서버에 안 남음).
- 켜도 **원문은 안 나간다.** 로컬에서 만든 *주제별 요약(증류층)* 만 전송하며, **봉인 포착은 아예 제외**된다. 나간 내역은 설정의 **전송 기록**에서 날짜·종류·글자 수로 확인할 수 있다.
- 끄면(기본값) 모든 정리는 **온전히 로컬 AI(Apple Foundation Models)** 로만 만들어진다.

## 2. 화면 구성 — 5개 탭

하단 탭은 5개다. **빈 영역을 좌우로 쓸면** 옆 탭으로 넘어간다(좌→다음, 우→이전).

| 탭 | 아이콘 | 하는 일 |
|---|---|---|
| **포착** | 🎙️ | 말하거나 써서 생각을 남긴다 (입구) · 우상단 ⚙️ 설정 |
| **기록** | ☰ | 모든 포착을 최신순으로 본다 + 검색(전문·의미) |
| **주제** | ✚ | 자동으로 묶인 주제별로 본다 + 큐레이션 |
| **정리** | 📄 | 일일·주간·기간 회고를 만든다 (출구) |
| **흐름** | 📊 | 일별 포착·에너지 추이·주제 분포를 한눈에 |

**설정**은 포착 탭 우상단 ⚙️에서 카테고리별로: **저장 & 동기화**(Obsidian 볼트·백업), **정리 & 가공**(정리 템플릿·클라우드 깊은 종합), **알림**(저녁 회고), **도구**(받아쓰기 정확도).

---

### 2-1. 포착 탭 — 생각을 남기는 곳

화면 위에서 아래로: **봉인 토글 → 녹음 버튼 → 직접 입력칸**.

**① 음성으로 (기본)**
- 가운데 **마이크 버튼을 탭하면 녹음 시작.** "듣고 있어요 · 탭하면 저장"이 뜨고, 목소리 크기에 맞춰 링이 맥동하며 경과 시간이 보인다.
- **다시 탭하면 정지·저장.** 자동으로 받아쓰기(STT)가 돌아 텍스트로 저장된다. 가벼운 추임새("음/어/응" 등 단독 토큰)는 보수적으로 정리된다.
- 녹음 중 **음향 에너지(각성도)** 를 뽑은 뒤 **오디오 원본은 즉시 폐기**한다. (목소리 점수만 남고 음성 파일은 안 남는다.)

**② 글로 (폴백)**
- 아래 "또는 직접 입력" 칸에 쓰고 **저장**. 길어지면 칸이 아래로 늘어난다(최대 6줄, 그 이상은 내부 스크롤). 키보드 위 **완료**로 닫는다.

**③ 봉인 (🔒)**
- 위 **봉인** 칩을 누르면 보라색 봉인 모드. 이 상태로 저장한 포착은 **기기 밖으로 절대 안 나간다**(Obsidian은 별도 `봉인/` 폴더, 클라우드 종합엔 제외).
- 아주 사적인 생각용. 일반 포착과 같은 화면에서 자물쇠로 구분된다.

**저장 직후** 백그라운드에서 조용히: 임베딩 생성 → 주제 배정/생성 → (볼트 있으면) 마크다운 미러. 사용자는 기다릴 필요 없다. 저장하면 **"예전에 비슷한 생각"** 메아리가 잠깐 떠 과거의 나와 이어준다(봉인 제외).

**④ 앱 밖에서 한 동작으로** — 액션 버튼·Siri·AirPods("Siri야, 생동하는 기록에 포착")·홈/잠금화면 위젯·제어 센터로 트리거하면 앱이 포착 화면으로 열리며 **자동 녹음**(봉인 변형 포함). 저녁 회고 알림으로도(아래 그 밖의 기능).

> 톱니(⚙️)는 이 탭 우상단에 있다(설정 진입).

### 2-2. 기록 탭 — 모든 포착, 최신순

- 모든 포착을 시간 역순으로 본다. 각 행: 본문 + 날짜/시간 + (있으면)에너지 막대 + 주제 칩 + (봉인이면)🔒.
- **기간 칩**(상단): 오늘 · 1주 · 1개월 · 전체 · 기간(직접 지정)으로 좁혀 본다.
- **검색**(상단 검색창): **정확히 포함**(전문, 즉시) + **비슷한 기록(추정)**(의미 검색, 리턴 시) — 단어가 안 겹쳐도 뜻으로 찾는다.
- **행을 길게 누르면** 컨텍스트 메뉴:
  - **다른 주제로 옮기기** — 다른 주제 목록 중 선택, 또는 **새 주제로 추출**.
  - **기록 삭제** — 포착과 그 Obsidian `.md`까지 지운다. 그게 주제의 마지막 기록이면 빈 주제도 정리.

---

### 2-3. 주제 탭 — 자동으로 묶인 생각들

비슷한 포착이 자동으로 **주제(Theme)** 로 묶인다. 주제 묶기는 **온디바이스 AI의 best-effort**다(완벽하지 않음 — 아래 §5 참고). 그래서 **큐레이션(손보기)** 이 핵심이다.

- 목록: 주제 이름 + 포착 수. 탭하면 그 주제의 포착들(수동 정렬순).
- **주제를 길게 누르면**: **이름 변경**, **다른 주제로 합치기**.
- 주제 상세에서 **우상단 ⋯ 메뉴**: 이름 변경 / 합치기. 개별 **기록을 길게 누르면** 다른 주제로 이동·추출.
- 이름 변경·이동·합치기를 하면 Obsidian의 `[[주제]]` 위키링크도 자동으로 다시 써진다.

> 자동 분류가 어긋나도 괜찮게 설계됐다. **틀리면 손으로 옮기면 된다** — 그게 정상 흐름이다.

### 2-4. 정리 탭 — 돌아보기 (앱의 출구이자 핵심 가치)

우상단 **"정리 만들기"(✚) 메뉴**에서 셋 중 하나:

**① 일일 정리 (오늘)** — 로컬 전용
- 오늘 포착을 주제별로 모아 **통찰 중심 서술**(나열이 아닌 흐름)로 4~6문장.
- 직전 7일과 **이어지는 흐름(🔁 반복)** 을 연결해 무엇이 이어지고 무엇이 새로운지 짚음.
- 끝에 **내일 이어볼 질문** 하나.

**② 주간 회고** — 핵심 가치 ⭐ (앱의 심장)
시트로 열리며, 위에서 아래로 **"지속 루프"** 순서를 따른다 — 돌아봄 → 이어갈 것 → 놓을 것 → 다짐 → 연결 → 글:

1. **지난 회고 이후** *(돌아봄 — 루프를 닫는 머리)*
   - 지난번 내린 결정의 *지금*. **지속**한 게 이어졌나(이번 주 N회 ✓) / 조용해졌나, **접은** 게 다시 올라왔나(↑). 결정이 다음을 비춘다. *(한 주기 지나야 보임)*
2. **지속 후보** — 이번 주(7일) **2회 이상** 돌아온 주제들. 각 후보에 신호 배지:
   - **↑ 떠오름 / ↓ 식어감** — 최근 절반(3일) vs 이전 절반(4일) 활동률. *모멘텀.*
   - **🌱 진화 / 🔁 맴돎** — 생각이 옮겨갔는지(전·후반 임베딩 중심 거리).
   - **에너지 %, 열 ↑/↓** — 평균 에너지와 그 추세.
   - 정렬은 **지속 가치 점수**(반복 중심 + 모멘텀·에너지·진화 가산) 순.
   - 각 후보에 **[지속] [보류] [접기]** → 저장되고 다음 회고(1번)에 반영.
   - **선례**(🕘) — 전에 이 주제를 결정한 적 있으면 "30일 전 '보류' 결정 (3번째) → 그 뒤 4회 더"처럼 그 전적을 보여줌. *지금 누르기 전에* 과거가 거든다.
3. **❄️ 식어가는 줄기** *(가지치기)* — 한때 자주 다뤘는데(직전 2주 ≥3회) 요즘 조용해진(최근 ≤1회, 4일+) 주제. **[되살리기]**(다시 이어가기) / **[접기]**(놓아주기). *지속 = 이어가기 + 가지치기.*
4. **이번 주 다짐** *(실행 추적)* — 포착 속 "~하겠다/해봐야지" 같은 의도를 자동 감지해 모은 것. 같은 주제가 이어지면 **이어지는 중 ✓**, 10일+ 잠잠하면 **잠잠해짐**. (자동 감지 — 참고용)
5. **연결된 주제** *(영감)* — 서로 가까운 주제 쌍. **새 연결**(이번 주 처음 가까워짐)·**강/중** 배지 + **[한 줄기로 묶기]** 한 탭(작은 쪽을 큰 쪽으로 합침).
6. **주간 서술** — "주간 정리 생성"으로 회고 글 생성. 위 신호(돌아봄·떠오름/식어감·다짐·새 연결)를 엮어 통찰로. 클라우드 ON이면 ☁️ 깊은 종합(증류층만 전송), OFF면 로컬.

**③ 기간 정리** — 임의 구간
- 최근 N일(또는 전체)의 반복 주제 + **"내린 결정과 그 이후"**(이어짐/다시 올라옴/정리됨) 누적 로그를 종합. 큰 흐름 요약. 클라우드 옵트인 동일.

생성된 정리는 목록에 쌓이고(상단 **기간 칩**으로 좁혀 봄), 볼트가 있으면 `Digests/`에도 저장된다.

### 2-5. 흐름 탭 — 한눈에 + 되살아남

- **되새김** *(과거가 안부)* — 가만히 있어도 하루 한 번, 14일+ 이전의 포착 하나가 올라온다. **"N년/개월 전 오늘"** 또는 **"한동안 잊고 있던"**. (반추 함정 방지로 봉인 제외·시끄러운 최근 편향 없음)
- **오래 이어진 줄기** *(throughline)* — 한 번 불타고 끝난 게 아니라 **여러 시기를 가로질러**(30일+·서로 다른 3주+) 거듭 돌아온 주제. "내가 한결같이 마음 쓴 것."
- **차트** — 요약(포착·주제·평균 에너지·봉인) + 일별 포착 수(14일) + 에너지 추이 + 주제 분포(Top 8). *(Swift Charts)*

## 2-9. 그 밖의 주요 기능

- **저녁 회고 리마인더** — 매일 정한 시각, 그날의 **되새김을 담은 알림**(없으면 "오늘을 한 줄로"). 탭하면 흐름/포착으로. *기기 안에서만.* (설정 → 알림)
- **LLM 위키** — 볼트를 LLM이 길찾아 읽는 지식 베이스로. 주제마다 **허브 노트**(`Themes/<주제>.md`: 메타 + 결정 + 기록 목록 + 클라우드 "한눈에") + **`index.md`**(줄기 + 모든 주제). 새 포착·큐레이션 때 자동 갱신, 기존 데이터엔 **"위키 다시 빌드"**. AI 한눈에는 클라우드 옵트인(증류·봉인 제외). 단방향(앱→볼트). (설정 → Obsidian 볼트)
- **암호화 백업·복원** — 전체 데이터를 암호로 잠근 파일 하나로 내보내기/복원(봉인 포함, 같은 암호로 병합). (설정 → 백업 & 복원)
- **정리 템플릿** — 정리 글의 톤·초점을 고르거나 직접 만든다(따뜻한 통찰/간결/질문 중심/행동 제안 + 자유 작성). (설정 → 정리 템플릿)

## 3. 핵심 개념 정리

| 개념 | 뜻 | 어떻게 쓰나 |
|---|---|---|
| **포착(Capture)** | 한 조각의 생각(음성→텍스트 또는 직접 입력) | 포착 탭에서 만듦 |
| **봉인(Sealed)** | 기기 밖으로 안 나가는 포착 | 포착 시 🔒 토글 |
| **에너지** | 말할 때의 각성도(음량 기반 0~100%) — *감정 분석 아님* | 자동, "평소 대비"로 해석 |
| **주제(Theme)** | 비슷한 포착의 묶음 | 자동 + 손으로 큐레이션 |
| **모멘텀** | 최근 흐름(떠오름/꾸준/식어감) | 주간 회고 배지 |
| **진화/맴돎** | 생각이 발전했나/제자리인가 | 주간 회고 배지 |
| **지속 후보** | 자주 돌아오는 주제 | 주간 회고에서 결정 |
| **결정(Decision)** | 지속/보류/접기 | 회고 글·기간 정리에 반영 |
| **다짐(Commitment)** | 포착 속 자동 감지된 의도 | "이번 주 다짐"에서 생존 추적 |
| **냉각(식어가는 줄기)** | 한때 뜨거웠다 조용해진 주제 | 되살리기/접기로 가지치기 |
| **연결(Connection)** | 가까운 두 주제(영감) | "한 줄기로 묶기" |

> **지속 루프**: 포착 → 주제 → 신호(반복·에너지·진화·**실행·냉각·연결**) → 결정 → 실행 추적 → "지난 회고 이후"로 피드백. 이 고리가 앱의 핵심 가치 "무엇을 지속할 것인가"를 돕는다.

## 4. 프라이버시 — 무엇이 어디에 있나

```
[음성] ──녹음──▶ 에너지 점수만 추출 ──▶ 오디오 즉시 폐기 (파일 안 남음)
                                          │
[텍스트/전사된 글] ──▶ SwiftData(기기 로컬) ──▶ (선택) Obsidian 볼트 .md
                                          │
                       ┌──────────────────┴───────────────────┐
                  기본(클라우드 OFF)                  클라우드 ON(선택)
                  모든 정리 = 로컬 AI               주간/기간만 = Claude
                                                   단, 원문 X → '증류층'(주제별 요약)만 전송
                                                   봉인 포착 = 항상 제외
                                                   전송 내역 = 설정에 기록
```

- **2단계 증류:** 원문은 로컬에만. 클라우드엔 로컬 AI가 만든 *요약*만. 원문 인용 없이 추상화.
- **동의 모델:** "한 번 켜기 + 봉인 예외 + 전송 로그". 매번 묻지 않되, 봉인은 늘 빠지고, 나간 건 다 보인다.
- 비밀키는 **Keychain**, 코드에 하드코딩 없음.

## 5. 알아둘 한계 · 주의 (정직하게)

- **실기기 전용 기능:** 받아쓰기(SpeechTranscriber)는 **시뮬레이터에서 음성 에셋이 취약**하다. 음성 포착은 실제 iPhone에서 테스트할 것. (실기기 실음성 문자 정확도 ≈ 92.8% 측정됨.)
- **자동 주제 분류는 best-effort:** 온디바이스 AI(Foundation Models)는 환경에 따라 한 주제로 **쏠리거나 과하게 갈라진다.** 그래서 설계가 "자동 + 큐레이션"이다. **어긋나면 주제 탭에서 손으로 옮기는 게 정상 흐름.**
- **FM 가드레일:** 무해한 문장도 가끔 로컬 AI가 거짓 차단할 수 있다(요약/이름짓기 실패 시 개수·앞글자 폴백으로 처리). MLX 오픈모델 폴백은 검증됐으나 v1 앱엔 아직 번들 안 됨.
- **신호는 데이터가 쌓여야:** 진화/맴돎은 임베딩 3개+, 에너지 추세는 에너지 포착 4개+, 모멘텀·지속 후보는 7일 내 2회+, **냉각**은 직전 2주 3회+ 뒤 조용, **다짐 생존**은 10일, **피드백("지난 회고 이후")**은 결정 후 한 주기가 지나야 의미가 생긴다. 초반엔 배지가 적게 보이는 게 정상.
- **의도 감지는 어미 게이트(결정적):** "~하겠다/해야지/해보자" 같은 한국어 의도 어미로 잡아 환경에 안 흔들린다(FM Bool 판정은 불안정해 버림). 드물게 과발화 가능("좋겠다"=소망)하고, 다짐 *라벨*은 FM이 뽑아 품질이 들쭉날쭉할 수 있다. 신호의 **임계값들은 실사용 데이터로 튜닝 예정**(현재는 보수적 기본값).
- **iCloud 볼트 = 봉인 유출 위험:** §1-2 주의 참고.
- **단일 기기:** v1은 기기 간 동기화 없음(iCloud 동기화는 후속). 백업은 수동.

## 6. 데이터 모델 (한눈에)

- **Capture** — 한 포착: 텍스트, 생성시각, 에너지?, 봉인여부, 태그후보, 임베딩(512d)?, 주제?, 정렬값.
- **Theme** — 주제: 이름, 상태(활성/맴돎/냉각/결정됨), 포착들, 위키 "한눈에" 요약?.
- **Digest** — 정리: 종류(일일/주간/기간), 기간, 서술글, 클라우드생성여부.
- **Decision** — 결정: 주제, 판정(지속/보류/접기), 시각.
- **Commitment** — 다짐(의도): 의도구, 시각, 상태(진행/이어짐/잠잠), 주제ID 스냅샷.
- **CustomTemplate** — 사용자 정리 템플릿: 이름, 스타일 지시.
- **Transmission** — 클라우드 전송 로그: 종류, 글자 수, 시각.

> 향후 채점/코멘트 등 확장 테이블을 붙일 수 있게 모델은 열려 있다.

## 7. 기술 스택 (참고)

SwiftUI + SwiftData / Apple 온디바이스 AI 올인:
- STT = **SpeechTranscriber** (한국어 on-device)
- 로컬 LLM = **Foundation Models** (+MLX 폴백 예정)
- 임베딩 = **NLContextualEmbedding** (한국어, *중심화 전처리 필수*)
- prosody = **vDSP** 음향특징(각성도)
- 로컬 텍스트 생성 = **LocalSynth**(FM → MLX 폴백 자리) · 깊은 종합(옵트인) = **Claude (Sonnet)** = `CloudSynthesizer`
- 핵심 컴포넌트는 **인터페이스로 추상화**(Transcriber/ProsodyAnalyzer/Embedder/ObsidianMirror/IntentionDetector) → 교체 가능.
- 검색·신호 = **NLContextualEmbedding**(중심화) 코사인 + 결정적 신호(어미 게이트·날짜창). *주제 간 자동 연결은 임베딩 신뢰 불가로 미채택.*
